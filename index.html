▸ ПОДКЛЮЧЕНИЕ · DONATEX
External-токен

DonateX: кабинет → Настройки → API и доступ → скопируй external-токен. Сайт подтянет историю донатов, топ за месяц, цель сбора и живые события через SignalR. Проверить можно кнопкой тестового доната в кабинете — он появится в ленте сразу.

Токен хранится только в твоём браузере (localStorage) и никуда не отправляется, кроме API DonateX. Для публичного сайта на много стримеров используй OAuth + PKCE.

▸ ПОДКЛЮЧЕНИЕ · DONATIONALERTS
Client ID
Redirect URI
access_token

DonationAlerts: donationalerts.com/application/clients → создать приложение (тип Implicit / браузерное), scope: oauth-user-show oauth-donation-index oauth-donation-subscribe, Redirect URI — адрес этого сайта. Кнопка «ВХОД DA» откроет авторизацию: после входа токен вернётся в адресной строке (после #access_token=), сайт подхватит его сам.

Донаты DA отображаются в исходной валюте без конверсии в рубли.
