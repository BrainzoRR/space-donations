SPACE DONATIONS — пиксельный космо-сайт с топом донатеров
space-donations-site · 
32352

Что внутри

🎨 Дизайн — пиксельный космос: мерцающие звёзды + цветные туманности на canvas, падающие метеоры, CRT-сканлайны, шрифт VT323, неоновые панели, медали 🥇🥈🥉, и у каждого донатера — уникальная пиксельная аватарка (генерируется из ника).

⚙️ Функции:

  • Топ-12 донатеров с суммами, числом донатов и их лучшим сообщением
  • Живая лента донатов с цветовой кодировкой (текст / крупный / голосовое / кружочек / тест)
  • Цель сбора с пиксельным прогресс-баром (DonateX)
  • Всплывающий алерт на крупный донат (≥300₽)
  • Статус-панель состояния обоих сервисов
  • Демо-режим без токенов — эмуляция донатов

Как подключить

DonateX (самое простое): donatex.gg → кабинет → Настройки → API и доступ → скопируй external-токен → вставь на сайте → «ПОДКЛ.». Реалтайм работает через SignalR1, история и топ — через REST23.

DonationAlerts: создай приложение на donationalerts.com/application/clients (тип Implicit, scope oauth-user-show oauth-donation-index oauth-donation-subscribe) → вставь Client ID и адрес сайта → «ВХОД DA». Реалтайм — через Centrifugo WebSocket4.

Важно про публикацию

Сайт — один HTML-файл, можешь закинуть его на GitHub Pages / Netlify / Vercel (скачать: space_donations.html). Один нюанс: DonateX пока не подтверждён, что разрешает браузерные запросы (CORS) со сторонних страниц. Если увидишь ошибку CORS — скажи, добавлю кнопку с проверкой и разберёмся (или оформлю мини-прокси). DonationAlerts в этом плане дружелюбнее, но у DA токен живёт ~2 недели, потом просто перезайди.

Хочешь — добавлю ещё: звук на алерты, конфетти при крупном донате, выбор периода топа (день/неделя/всё время) или твой ник в шапку?

Продолжаю. По картинке понял направление: оставляем текущую основу, но сильнее подгоняем под показанный терминал — меньше «глянцевого сайта», больше компактных панелей корабельной консоли, тонкие синие рамки, жёлтые акценты только для лидера и сумм, пиксельные аватарки и статусные индикаторы.

Сейчас важный момент по DonationAlerts: Redirect URI — это не отдельный обязательный домен DA. Это адрес, на который DA вернёт пользователя после авторизации. Поэтому нужен адрес, по которому открывается сам твой сайт.

Для тебя варианты такие:

  • если сайт уже опубликован — укажи полный URL страницы, например https://myname.github.io/space-donations/;
  • если сайта пока нет — сначала опубликуй HTML на GitHub Pages или Netlify;
  • если сайт открыт локально как файл — file://... для OAuth DA обычно неудобен, лучше получить временный или постоянный https://-адрес.

Redirect URI в приложении DA должен полностью совпадать с адресом сайта, включая конечный /. Например:

Plaintext
https://myname.github.io/space-donations/

И такой же адрес нужно вписать в поле Redirect URI на самом сайте. После этого авторизация будет работать кнопкой «ВХОД DA».

Ещё я бы поправил архитектуру так:

  1. DonateX подключаем external-токеном и SignalR.
  2. DonationAlerts подключаем через OAuth.
  3. Историю DA и запрос centrifuge/subscribe отправляем через маленький Cloudflare Worker-прокси из-за CORS.
  4. Сам realtime WebSocket DA оставляем прямым — проксировать WebSocket через этот Worker не требуется.
  5. На странице добавляем выбор периода топа: день, неделя, месяц, всё время.
  6. Визуально делаем карточку первого места крупнее, с пиксельным космонавтом из изображения и жёлтой рамкой.

В предыдущем варианте сайта уже есть поле для CORS-прокси. Если у тебя пока нет URL прокси, это нормально: он не нужен для самого Redirect URI, но понадобится, когда браузер начнёт получать данные DA и покажет ошибку Failed to fetch.

Важно: после смены модели рабочая sandbox-сессия перезапустилась, поэтому локальная копия предыдущего HTML-файла сейчас недоступна в текущем окружении. Сам ранее экспортированный файл можно продолжать использовать по этой ссылке: space_donations.html.Продолжил с учётом картинки. Стиль понял так:

  • тёмный космический терминал;
  • компактные панели с тонкими синими рамками;
  • жёлтый цвет только для логотипа, сумм и первого места;
  • пиксельные аватарки и космонавт/корабль в карточках;

  • минимум обычных веб-элементов, максимум ощущения интерфейса космического корабля.

По URL для DonationAlerts: отдельный домен DA тебе не нужен. В качестве Redirect URI укажи адрес самого опубликованного сайта.

Например:

Plaintext
https://твой-ник.github.io/space-donations/

Этот же адрес укажи в поле Redirect URI на странице сайта. Он должен совпадать полностью, включая / в конце.

Если сайта пока нет, самый простой путь:

  1. Создать репозиторий на GitHub.
  2. Загрузить файл сайта под именем index.html.
  3. Включить Settings → Pages.
  4. Получить адрес вида:
Plaintext
https://твой-ник.github.io/название-репозитория/
  1. Вставить этот адрес в настройки приложения DonationAlerts.
